# Raihana HIS UI/UX V2 — Codex Prompt Pack

This folder is a revised prompt pack for redesigning the frontend of a Frappe-based Hospital Information System.

## What was added in V2

- Floating sidebar
- Floating glass top navigation
- Command palette and global search
- Border Beam component rules
- Spotlight and pointer-aware cards
- Soft glow and animated borders
- Magnetic/spring buttons
- Animated navigation indicators
- Bento dashboard guidance
- Resizable/split panel guidance
- Context menus and keyboard shortcuts
- Rich tooltips and accessible interactions
- RTL/LTR requirements
- Frappe-specific integration safety rules
- License/source recording for external components
- Clear restrictions preventing visual effects on dense clinical surfaces
- Testing, screenshots, performance, reduced-motion, and changed-files evidence

## How to use

1. Fill in the technical context after Codex audits the repository.
2. Send Phase 1 only.
3. Review screenshots and test evidence.
4. Approve or request corrections.
5. Continue one phase at a time.
6. Do not send all phases as one implementation request unless Codex is only being asked to review or plan.

## Important

The premium effects are deliberately opt-in. Clinical tables, forms, alerts, medications, lab results, and patient-safety information must remain calm, immediate, and readable.
